# sensor-simulation-thesis
Questo repository contiene il codice sorgente Python utilizzato per la modellizzazione e la validazione del sensore ottico descritto nella tesi di laurea:[titolo da ridefinire]
Il software funge da ponte tra la progettazione ottica e la risposta biochimica, permettendo di quantificare la sensibilità del sistema in condizioni cliniche reali. Il cuore del codice risiede nell'integrazione tra la teoria della diffrazione e la biochimica enzimatica. Interfaccia con Quadoa: Il modulo di parsing XML (carica_parametri_automatico) estrae in tempo reale i parametri geometrici e materiali dal file di progetto .optx, garantendo una corrispondenza univoca tra il modello virtuale e la simulazione. Modellazione Cinetica: L'implementazione dell'equazione di Michaelis-Menten permette di simulare il turnover enzimatico della Glucosio-Ossidasi (GOD) all'interno della matrice MIP, trasformando il substrato in variazione dell'indice di rifrazione locale. Analisi di Sensibilità e Linearità: Il codice calcola lo shift angolare teorico e il coefficiente di linearità ($R^2$), permettendo di mappare la risposta del sensore rispetto alle soglie di ipoglicemia, normoglicemia e iperglicemia. Il workflow è automatizzato per supportare la validazione multi-materiale. Configurazione: Il file template_config.optx funge da input primario per le proprietà fisiche del reticolo.Analisi: Lo script calcola la risposta del sensore per un target di concentrazione definito dall'utente, confrontandola con il catalogo di materiali definito nel dizionario CATALOGO_INDICI.Output: Il sistema genera automaticamente grafici di sensibilità angolare e linearità, salvando i log dettagliati per la tracciabilità dei dati.Note MetodologicheIl modello assume una variazione dell'indice di rifrazione legata alla concentrazione di analita tramite il coefficiente specifico $dn/dc = 0.185 \, \text{mL/mg}$. L'accuratezza della simulazione è garantita dal calcolo dinamico dello shift angolare mediato su diverse lunghezze d'onda, riflettendo la risposta reale dello spettrometro.Codice sviluppato per scopi di ricerca accademica.
